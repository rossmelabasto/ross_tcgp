# Security

`ross_tcgp` runs `adb` commands on a phone you connect, downloads card data and
images over HTTPS, and writes only under `~/.cache/ross_tcgp` and
`~/.local/share/ross_tcgp`. It never sends your collection anywhere.

To report a vulnerability, please open a private
[security advisory](https://github.com/rossmelabasto/ross_tcgp/security/advisories/new)
instead of a public issue.
